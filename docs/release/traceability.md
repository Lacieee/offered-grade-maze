# Traceability: the 28 success criteria (spec §23) → evidence

Release 1.0.0. Each row names the evidence that proves the criterion: an automated test
(file and test name), a screenshot baseline, a report, or a human gate. "e2e" tests are in
`e2e/tests/` (Playwright; the real-API ones run with `E2E_API=1`, as in CI); unit tests sit
next to the code (Vitest). G1–G4 are the product owner's gates; rows marked "sign-off" or
"pending" are confirmed by the product owner when walking through this table at G4.
